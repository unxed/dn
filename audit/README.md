# audit: поиск кода Borland

- `fetch_reference.sh [архив]` скачивает BP 7.0 + 7.01 (ссылка и sha256 в скрипте и в
  `PLAN.md`) и извлекает в `audit/ref/` 72 файла исходников, связанных с TV (включая
  Memory из примеров Graph Vision 2.3). Список пишется в `audit/ref/list.txt`.
  **`audit/ref/` не коммитится:** это проприетарный код. Нужен `unrar`.
- `xclone.py --ref audit/ref/list.txt КАТАЛОГ` находит в `КАТАЛОГ` дословные цепочки из
  24 токенов, которые есть в эталоне. Колонки описаны в докстринге и в
  `research/2026-10-01-provenance.md`.
- `runs.py ФАЙЛ audit/ref/list.txt [48]` перечисляет совпавшие цепочки (от 48 токенов):
  номера строк, процедура, место у Borland. Используется, чтобы найти, что переписывать.
- `cclone.py --base A --other B КАТАЛОГ` — то же для C/C++, с двумя эталонами: колонка
  `only%` показывает код, совпадающий с `B`, но отсутствующий в `A`. Так проверялось
  происхождение magiblot/tvision (`research/2026-10-01-magiblot-provenance.md`).
- `reports/<дата>/` — отчёты по исходникам самого DN (наш список работ): только имена
  файлов и цифры, кода в них нет. Отчёты о сторонних проектах сюда не кладём.

Повторить отчёт:

    audit/fetch_reference.sh            # или: audit/fetch_reference.sh путь/к/архиву.rar
    python3 audit/xclone.py --min 3 --ref audit/ref/list.txt путь/к/исходникам

Фон у чистого кода: `raw%` 0–1 %, `ren%` 5–10 %. Подозрение — это `raw%` выше 6 % или
`maxrun` от 48 токенов. Пороги ещё не откалиброваны (см. `PLAN.md`).
