# dn/: DOS Navigator

Здесь описано, как получить DOS Navigator поверх пакета [`tv/`](../tv/README.md). Самих
исходников DN в репозитории нет: они берутся из публичного архива и не хранятся.

## Что лежит в каталоге

| Файл | Что |
|---|---|
| `upstream.env` | адрес публичного архива, его sha256, каталог с исходниками внутри архива |
| `exclude.list` | файлы архива, которые не берём: их заменил новый TV или мы их переписали (в них код Borland-происхождения) |
| `patches/` | серия патчей по чистым файлам (`series` — порядок); у каждого патча указана причина |
| `new/` | наши новые файлы (лицензия DN) |
| `TODO-later.md` | что не делаем в первой версии |

## Как получить дерево

    tools/dn-fetch.sh          # скачать архив, проверить sha256
    tools/dn-materialize.sh    # распаковать, убрать исключённое, применить патчи, добавить новое
                               # результат — build/dn/ (в git не попадает)

## Правила

1. Первая версия — оригинал с минимумом изменений. Допустимые причины патча: (а) переход
   на новый TV; (б) UTF-8, если он есть в DOS; (в) LFN; (г) системный буфер обмена;
   (д) сборка современным компилятором. Всё остальное — в `TODO-later.md`.
2. Патч касается только файла, прошедшего ворота аудита (`audit/`), чтобы в его контексте
   не было кода Borland. Файл с кодом Borland целиком в `exclude.list`.
3. Код берётся только из публично доступных источников и нашего нового кода.
4. Лицензия DN (из публичного выпуска) на код DN; перелицензировать его нельзя. Код `tv/`
   (MIT + Borland) сюда не копируется: DN использует TV только как пакет.

## Условия лицензии DN, которые надо выполнять

Лицензия в заголовке исходников DN OSP (BSD-подобная, RIT Research Labs) требует: сохранять
уведомления об авторских правах; в двоичном виде воспроизводить их в документации; при
упоминании программы в рекламе указывать «Based on Dos Navigator by RIT Research Labs»;
код, производный от DN, нельзя перелицензировать (в том числе под GPL). Эти условия
переносятся на всё, что мы публикуем из `dn/`.
