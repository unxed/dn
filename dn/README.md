# dn/: DOS Navigator

Здесь будет сам DOS Navigator на Free Pascal поверх пакета [`tv/`](../tv/README.md).
Пока пусто: веха 4 плана ([`../PLAN.md`](../PLAN.md)).

## Лицензия

Лицензия DN (текст — из публичного выпуска, с которого берём код); перелицензировать
код DN нельзя, мы и не перелицензируем. Код `tv/` (MIT + Borland) сюда не копируется:
DN использует TV только как пакет.

## Откуда берётся код

1. Только из публично доступных источников: выпуски DN от RIT и DN OSP (ссылки и sha256 —
   в `UPSTREAM.md`, который появится с первым импортом) и наш новый код.
3. Исходники публичного выпуска в репозиторий целиком не кладём: файлы импортируются
   скриптом после аудита. Файл попадает в `dn/` только если проходит ворота `audit/`
   (нет совпадений с Borland выше порога); остальное заменяется аналогом из `tv/` или
   переписывается по спецификации поведения (`spec/`), без чтения исходника Borland.
4. Каждый импортированный файл записан в `UPSTREAM.md`: исходный архив, путь, результаты
   аудита.
