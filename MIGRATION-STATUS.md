## Safe automation and classification

The repository already contains the safe, lexer-based caret migration tools:

- `tools/class_names.py`
- `tools/class_carets.py`
- `tools/tests/test_class_carets.py`

They distinguish class references from record pointers, comments, strings,
casts and indexed pointers. Run the tests before using or changing them:

```sh
cd /home/unxed/dev/dn
python3 -m unittest discover -s tools/tests -p 'test_*.py'
```

Read-only planning scan:

```sh
python3 tools/class_carets.py --types dn/src tv/src --rewrite dn/src tv/src
```

Do not pass `--apply` while the migration batch is uncommitted.

Read-only parallel scanners may inspect independent units, but only one
process may edit a given file. Keep edits sequential, compile-driven and
checkpointed.

## Handoff rules

- Work only in `/home/unxed/dev/dn` and the separate `/home/unxed/dev/tv3`

  to `origin/classes/tv3-dependency`.
